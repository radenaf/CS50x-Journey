# Rickettsial Laboratory Website

Standalone export of the static website for the Rickettsial Laboratory, Bacteriology Department, Institute for Medical Research, National Institutes of Health, Malaysia.

Important:

- This project uses clearly labeled placeholder content for all unconfirmed official laboratory information.
- No laboratory claims, staff details, publications, or contact details should be treated as final until replaced with approved content.

Project structure:

- `index.html` and the other `.html` files are the site pages.
- `content/` contains structured placeholder data.
- `components/` contains shared rendering helpers.
- `scripts/` contains site behavior.
- `styles/` contains the shared stylesheet.
- `assets/` contains placeholder graphics and downloadable placeholder files.

Local preview:

```bash
cd rickettsial-laboratory-website
python3 -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
